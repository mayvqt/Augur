# Security

Report suspected vulnerabilities privately through [GitHub's security advisory form](https://github.com/mayvqt/Augur/security/advisories/new).
Please do not disclose vulnerabilities in public issues until a fix and disclosure plan are agreed.

Security fixes are supported for the latest published release. Upgrade to the latest release before reporting an issue
against an older version.

Never include Discord tokens, Seerr API keys, `.env` files, secret files, or database backups in issues, logs, or public
attachments. Redact them before sharing diagnostics.
